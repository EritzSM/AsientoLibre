# HU-22 — Organización visual de funcionalidades

**Como** usuario de Asiento Libre  
**Quiero** visualizar las funciones principales agrupadas y ordenadas según mi rol  
**Para** encontrar rápidamente las acciones que necesito sin recorrer contenido irrelevante.

## Criterios de aceptación

1. Al iniciar sesión, el usuario ve accesos directos únicamente a las secciones disponibles para su rol.
2. Las secciones presentan títulos, descripciones, estados vacíos y acciones con una jerarquía visual consistente.
3. La organización se mantiene clara y utilizable en computador y celular.

## Subtareas

- Crear un panel de accesos rápidos por rol.
- Unificar la presentación visual de las secciones principales.
- Probar visibilidad, navegación y compilación responsive.
